QuietBuzz

Most Android phones only stay quiet if you turn notifications off one app, one channel at a time — and the setting resets every time you install something new. QuietBuzz does the opposite: it silences sound and vibration everywhere except a small allowlist you choose, while keeping every notification fully visible in the shade. No Do Not Disturb icon, no forgotten muted apps, no re-tuning after every new install.

대부분의 안드로이드 폰은 앱마다, 채널마다 일일이 알림을 꺼야만 조용해지고, 새 앱을 설치할 때마다 그 설정은 다시 초기화됩니다. QuietBuzz는 반대로 동작합니다 — 직접 고른 소수의 허용 목록만 남기고 나머지 모든 앱의 소리와 진동을 끄면서도, 알림 자체는 알림창에 그대로 보여줍니다. 방해 금지 아이콘도 없고, 깜빡 잊고 무음으로 남겨둔 앱도 없고, 새 앱을 설치할 때마다 다시 설정할 필요도 없습니다.

How it works작동 원리

Android normally refuses this. A notification channel's importance level controls sound and vibration, but only two kinds of caller can change another app's channel importance from outside that app: the single system-wide Notification Assistant role, or a NotificationListenerService whose app also holds a CompanionDeviceManager association — stated directly in Android's own API reference, not a workaround. QuietBuzz uses the second path: pairing with any nearby Bluetooth device (nothing about the device is used afterward — it's a permission token, not a connection) satisfies that requirement, then the listener lowers every non-allowlisted app's channels to IMPORTANCE_LOW — shown in the shade, no sound, no vibration.

안드로이드는 원래 이걸 허용하지 않습니다. 알림 채널의 중요도(importance)가 소리와 진동을 결정하지만, 다른 앱의 채널 중요도를 외부에서 바꿀 수 있는 건 딱 두 경우뿐입니다: 시스템 전체에서 단 하나만 존재하는 알림 어시스턴트(Notification Assistant) 역할이거나, CompanionDeviceManager 연결을 보유한 NotificationListenerService — 이는 안드로이드 공식 API 문서에 직접 명시된 내용으로, 우회 편법이 아닙니다. QuietBuzz는 두 번째 방법을 사용합니다: 근처 블루투스 기기 아무거나와 페어링하면(페어링 이후 그 기기는 전혀 사용되지 않습니다 — 연결이 아니라 권한 토큰일 뿐입니다) 이 조건을 만족하고, 이후 리스너가 허용 목록에 없는 모든 앱의 채널을 IMPORTANCE_LOW로 낮춥니다 — 알림창에는 그대로 보이지만 소리도 진동도 없습니다.

How to use it사용 방법

  1. Allow restricted settings제한된 설정 허용 Settings › Apps › QuietBuzz › ⋮ › Allow restricted settings — required for a sideloaded app. 설정 › 앱 › QuietBuzz › ⋮ › 제한된 설정 허용 — 사이드로드한 앱에는 필수입니다.
  2. Grant notification access알림 접근 권한 허용 Special access › Notification access › enable QuietBuzz. 특수 접근 권한 › 알림 접근 › QuietBuzz 활성화.
  3. Link a device기기 연결 Pick any nearby Bluetooth device from the system picker — it doesn't matter which. 시스템 선택 창에서 근처 블루투스 기기 아무거나 선택하세요 — 어떤 기기든 상관없습니다.
  4. Run now — or just wait지금 실행 — 또는 그냥 기다리기 New app installs are caught automatically from here on. 이후 새로 설치되는 앱은 자동으로 감지됩니다.
  5. Set battery to Unrestricted배터리 사용을 "제한 없음"으로 설정 Settings › Apps › QuietBuzz › Battery › Unrestricted. 설정 › 앱 › QuietBuzz › 배터리 › 제한 없음.
Worth knowing참고 사항 This is a personal, sideloaded project — not on the Play Store, no root required. If the paired device's association is ever revoked, QuietBuzz posts a notification asking you to re-link; it silences nothing until you do. Play 스토어에 올라가 있지 않은 개인용 사이드로드 프로젝트이며, 루팅이 필요 없습니다. 연결된 기기의 권한이 해제되면 QuietBuzz가 재연결을 요청하는 알림을 띄우며, 재연결 전까지는 아무것도 무음 처리하지 않습니다.
